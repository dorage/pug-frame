# @pug-frame/cli

pug-frame 파일을 자기완결적 HTML 문서로 변환하는 커맨드라인 도구.

```bash
npx @pug-frame/cli wireframe.pf -o wireframe.html
# 또는 전역 설치 후
npm install -g @pug-frame/cli
pug-frame wireframe.pf
```

- 문법: [docs/syntax.md](https://github.com/dorage/pug-frame/blob/main/docs/syntax.md)
- 옵션과 종료 코드: [docs/cli.md](https://github.com/dorage/pug-frame/blob/main/docs/cli.md)
